# Hela Laget – Svenskalag-synk (webbläsartillägg)

Tillägget låter knappen **Synka svar** på en träning eller match i Hela Laget
hämta kallelsesvaren från Svenskalag med användarens egen inloggning där.
Inget lösenord lämnar webbläsaren.

Efter ändringar: `python3 scripts/zip-extension.py` (skriver public/hela-laget-svenskalag.zip,
som laddas ner från sidan Svenskalag-synk).
